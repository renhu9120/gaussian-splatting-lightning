--------------------------------------------------------------------------------
一、Phase C-1 在做什么
--------------------------------------------------------------------------------
- 目标：让 quaternion 不再作为「SH → RGB 之后的后置颜色模块」，而是进入 appearance 的「主表示层」。
- 做法：
  · 每个 Gaussian 增加 4 维 quat_latents_raw；
  · 在 renderer 中：base_rgb（SH→RGB）+ quat_latent + view_descriptor（归一化相机中心）→ 极小 decoder（10→16→3）→ rgb_delta；
  · 最终颜色：rgb_pred = base_rgb + rgb_delta（residual 形式）；
  · decoder 最后一层零初始化，训练初期尽量贴近 baseline。
- 诊断量：diag_quat_latent_norm（latent 范数）、diag_rgb_delta_abs_mean（decoder 输出增量绝对值均值）。

三、简要解读
--------------------------------------------------------------------------------
1. 诊断量说明「模块在用」：
   - diag_quat_latent_norm：从 ~0.08 逐步升到 ~0.42，说明 quaternion latent 被训练、范数在增大；
   - diag_rgb_delta_abs_mean：全程在 0.14–0.32 之间，说明 decoder 一直在输出非零增量，没有退化成恒零。

2. 最终质量（step 10000）：
   - PSNR ≈ 35.32，SSIM ≈ 0.981，LPIPS ≈ 0.013，loss / rgb_diff 很低，说明在 Lego 上 Phase C-1 能训到很好的重建质量。

3. 中期波动（step 3000）：
   - step 3000 处 loss/rgb_diff 升高、PSNR 降到约 12.29、LPIPS 升到 0.285，明显差于 1000 和 5000；
   - 可能与 densification 在 500/1000 附近大量 clone/split 后，新点与 decoder 的联合适应有关，或为正常波动；需要与 baseline / Phase A / B 同 step 对比才能下结论。

4. 与 Phase A/B 的对比（需你补全）：
   - 若 baseline / phase_a / phase_b1–b3 在同一数据集、同一 step 的验证指标已有，可对比：
     · Phase C-1 最终 PSNR/LPIPS 是否更好、相当或更差；
     · step 3000 的回落是否只在 C-1 出现，还是其他 phase 也有类似波动。

四、建议与 ChatGPT 讨论的方向
--------------------------------------------------------------------------------
- Phase C-1 已证明：quaternion latent 作为主表示 + 极小 residual decoder 可以稳定训练，且诊断量显示模块确实被使用；最终指标在 Lego 上很好。
- 下一步可讨论：
  1. 是否先做「与 baseline / Phase A / B1–B3 的定量对比表」（同一 step、同一数据集），再决定是否认为 C-1 有收益；
  2. 是否尝试 Phase C-2「Freeze-Geometry / Appearance-Only」：冻结 means/scales/rotations/opacities，只训 shs + quat_latents + decoder，更直接检验 quaternion appearance 的贡献；
  3. 是否略微加大 decoder（如 hidden_dim 16→32）或调学习率，观察对 step 3000 波动和最终指标的影响；
  4. 是否引入轻量 quaternion 约束（如单位四元数归一化）或保持当前「无约束 4 维 latent」继续跑更多数据集（如 chair、ship）。
